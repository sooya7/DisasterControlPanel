# 灾难控制面板 · Disaster Control Panel 0.2.0

《城市：天际线 II》本地代码 Mod。十种灾难、1–10 级强度、地图选点、预警、停止和独立全城避难控制。

适配环境：Windows Steam 版 **1.6.2f1**。无需 BepInEx、Harmony 或额外前置 Mod。其他游戏版本未验证。

## 灾难

| 类型 | 行为 |
| --- | --- |
| 建筑火灾、森林火灾 | 指定实际建筑或野生树木起火，沿用原生消防和蔓延 |
| 冰雹、龙卷风、雷击 | 原生天气事件；冰雹接入原生降水粒子，空地雷击补接原生闪电特效；事件随后受风向影响 |
| 洪水 | 点击想淹的位置，附近水域逐渐上涨，水边一步步漫进相连的低洼街区；堤坝和高地挡住的地方不进水 |
| 海啸 | 点击想冲击的位置，海水先退，远海浪墙推进、越近岸越高，冲上岸后沿低地继续向内陆卷去，随后一道尾浪；高地幸免 |
| 地震 | 一条断层从震中向两侧撕开（雁列断段 + 分支），三轮震动逐次加宽、抬起断坎，裂口和建筑扬尘、镜头震动；沿用原生建筑损伤和倒塌 |
| 陨石 | 火球拖着发光尾迹和长烟迹从高空斜落，撞击火球、冲击尘环、蘑菇状烟柱、炽热碎岩、熔融坑冷却；真实坑洞、附近建筑损伤及起火 |
| 地面塌陷 | 自定义坑洞，坑内建筑进入原生倒塌流程 |

地震、陨石、塌陷是新增灾害实现，效果与一代不完全相同。建筑倒塌没有作为独立选项加入。

## 使用

进入城市，点击右下角 **灾难** 或按 **F9**。

1. 点击灾难类型，直接进入地图触发状态，沿用当前强度、时长等参数。
2. 左键点击地图，立即提交一场灾难；成功后自动退出触发状态。建筑火灾必须点击实际建筑，森林火灾必须点击野生树木。洪水、海啸直接点想影响的位置，无需自己找水源或选择方向。

右键、Esc 或面板中的 **取消** 可退出地图触发。再点灾难类型或 **在地图上触发** 可准备下一场，无需另行确认。

准备触发时仍可调整下方参数。洪水、海啸只保留 **强度和时长**，方向、水域与局部危险由程序和原生水体机制处理；海啸时长是造波时间。其他灾害保留当前强度、持续时间、预警和警报范围设置。陨石即使选择零预警，也会根据触发时的模拟速度保留可见的坠落过程。

面板中的 **发布全城避难** 可独立发出警报，无需触发破坏。**解除全城警报** 解除本 Mod 的全城警报；仍在发生的灾害保留局部危险。建筑火灾和森林火灾可用这个独立按钮配合避难。

Mod 只发出危险警报。居民是否避难、庇护所选择、道路寻路、学校/医院运输和巴士调度由游戏原生机制决定，Mod 不改写居民出行；冰雹和雷击保留原生留在室内规则。独立全城警报需要点击按钮发布，最多维持 1800 模拟秒，可提前解除。

暂停会暂停灾害倒计时与模拟；暂停状态下可设置和排队触发，恢复模拟后产生影响。停止只处理本面板创建的灾害，不修复已造成的损伤、火灾蔓延或坑洞。海啸停止后仍需等待尾波传播，水面不会瞬间恢复。

### 地形与水体

坑洞使用原生地形修改接口，可随另存保留。原版建筑地基和道路会覆盖部分坑形，清理废墟后可显露下方地形；本版不额外切断道路或管线。地震裂纹是地表视觉效果，不改变地形或道路。

新版水体在点击点周围 4096 米内自动寻找现有水域，海啸要求海水。点击陆地时朝点击位置推进，点击水面时朝附近岸边推进；海啸波前优先在所选海水的岸外形成。洪水沿相连的现有水面扩展涨水区域，不再要求存在原始水源实体。高等级同时提高水位和范围，10 级以大范围漫岸为目标，高地仍可能幸免。没有合适水域时提示靠近河湖或海岸；水流、漫岸与消退仍由原生模拟决定。旧水体使用最近的兼容原生水源。新版水灾不修改地图水源实体或全局海平面。

冰雹粒子在镜头进入受灾范围时显示，远景中的单颗冰雹不易分辨。手动雷击的首轮约在 1 模拟秒后出现，随后间隔 3–8 模拟秒；原生伤害和起火仍由游戏处理。

## 安装、恢复与卸载

退出游戏后，在解压目录执行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

安装脚本验证 DLL 的 SHA-256。旧版备份到 `%LOCALAPPDATA%/DisasterControlPanel/backups`，位于游戏扫描目录之外，避免备份 DLL 被再次加载。也可把 `mod/DisasterControlPanel.dll` 放到 `%USERPROFILE%/AppData/LocalLow/Colossal Order/Cities Skylines II/Mods/DisasterControlPanel/`。

先停止活动灾害、另存并退出，再运行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1
```

卸载将 Mod 移到 `%LOCALAPPDATA%/DisasterControlPanel/uninstalled` 保留恢复路径。恢复时退出游戏，将该备份的 DLL 放回上述 Mods 目录。卸载不会恢复城市破坏。
