# 本机原生灾难与事故核对

核对日期：2026-10-05。范围：本机 Windows Steam《城市：天际线 II》1.6.2f1 的 `Game.dll`、`resources.assets` 和对应 MonoScript 表。本轮为离线只读核对，没有新增灾害触发实测。

## 结论

原生资源中确认 **8 种灾害相关事件，另有 1 种车辆失控事故**。资源内置、组件启用、事件集合启用，不等于已经验证其全部游戏行为，也不等于官方将其作为常规随机自然灾害发布。

| 类型 | 原生 EventPrefab | 原生机制 | 本面板 0.1.0 |
| --- | --- | --- | --- |
| 建筑火灾 | Building Fire | Fire | 已接入，已有实机验收记录 |
| 森林火灾 | Forest Fire | Fire | 已接入，已有实机验收记录 |
| 冰雹 | Hail Storm | WeatherPhenomenon、TrafficAccident | 已接入，已有实机验收记录 |
| 龙卷风 | Tornado | WeatherPhenomenon、TrafficAccident、EarlyDisasterWarningEvent | 已接入，已有实机验收记录 |
| 雷击 | Lightning Strike | WeatherPhenomenon、Fire | 未接入，未做触发验收 |
| 建筑倒塌 | Building Collapse | Destruction | 未接入，未做触发验收；与地面塌陷不同 |
| 洪水 | Flood | WaterLevelChangeComponent：River / RainControlled | 未接入，未做触发验收 |
| 海啸 | Tsunami | WaterLevelChangeComponent：Sea / Sine | 未接入，未做触发验收 |
| 车辆失控事故 | Lose Control Accident | TrafficAccident、Fire | 未接入，未做触发验收；属于事故 |

这 9 个事件均在启用的 `EventsCollection` 中，Prefab 与上述核心组件的 `active` 均为 true。海啸和洪水的 Unlockable 依赖 `Natural Disasters`；建筑火灾、建筑倒塌、雷击依赖 `Fire & Rescue`。依赖名称是原生功能 Prefab，不意味着需要购买同名 DLC。

原生事件目录共识别 18 个 EventPrefab，见 [完整提取结果](native-event-inventory.json)。其他事件包括疾病、重伤、猝死、抢劫、火箭发射、情人节和出游活动，未计入灾害。

本机目录未发现地震、陨石、地面塌陷对应的原生 EventPrefab；相关代码类型检查也未找到对应的完整灾难系统。因此目前不能把它们作为直接接入的原生灾难。建筑倒塌不能替代地面塌陷。

## 海啸和洪水的代码证据及限制

- `Game.Events.InitializeSystem.InitializeWaterLevelChangeEvent` 存在初始化流程。海啸会得到原生强度、固定方向和持续帧数，手动控制需要处理初始化覆盖参数的问题。
- `Game.Simulation.WaterLevelChangeSystem` 对 `Sine` 类型计算波浪强度，并有 `TsunamiEndDelay`。
- `Game.Simulation.SoilWaterSystem` 存在 `StartFlood` / `StopFlood`，按降雨累计的 `FloodCounterData` 启动洪水，更新 `WaterLevelChange.m_Intensity`，并在计数回落时停止。因此不能只看 WaterLevelChangeSystem 的 RainControlled 空分支便认定洪水没有实现。
- `Game.Simulation.FloodCheckSystem` 存在水深与淹没处理。
- 尚未验证海啸自然发生入口、具体地图的海水源与传播方向、手动强度控制、水面恢复、停止和存档重载行为。洪水会被原生降雨系统更新，手动控制需要协调该系统。

## 官方公开范围与本机资源的区别

[官方《气候与季节》开发日志](https://www.paradoxinteractive.com/games/cities-skylines-ii/features/climate-seasons)于 2023-08-07 公开介绍的自然灾害为森林火灾、冰雹和龙卷风。该页面是发布前说明，不能代替本机 1.6.2f1 的完整资源目录。建筑火灾与救援见 [官方城市服务说明](https://www.paradoxinteractive.com/games/cities-skylines-ii/features/city-services-districts-policies)。

本轮更正：此前把海啸说成“不自带”不准确。海啸、洪水不只存在相关类名，还存在真实 EventPrefab、启用的组件和事件集合引用。0.1.0 未显示它们，是面板尚未接入，不能据此认定原版没有。
