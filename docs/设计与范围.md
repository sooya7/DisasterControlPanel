# 灾难控制面板 0.2

目标：在《城市：天际线 II》里提供接近一代的手动灾难工具：选择灾难、1–10 级强度、天气持续时间、点击地图触发、停止本 Mod 的灾害。

以本机 1.6.2f1 的 Game.dll 为接口依据。使用原生 EventPrefab、事件初始化、火灾、天气、消防与预警系统；自定义灾难通过原生损伤/倒塌事件和地形接口实施影响，不修改原版灾难 Prefab。为每种灾难注册 10 个稳定命名的强度变体，原生变体自发概率为 0，避免新增随机灾难。

本版提供建筑火灾、森林火灾、龙卷风、冰雹、雷击、洪水、海啸，以及自定义地震、陨石、地面塌陷，共十种。建筑倒塌和车辆失控事故不作为独立灾难选项。新增水体兼容修正、天气特效和原生避难调整仍待实机复测，见[修复记录](水灾与天气修复.md)与[0.2 验收记录](0.2验收记录.md)。

强度 5 为工具基准；其他等级调整火势/蔓延、天气损伤、影响范围和水源高度。天气按 60 个模拟帧/秒计时，暂停与倍速会影响现实中的持续时间。火灾由原生消防和蔓延系统处理，无法指定整场火灾持续时间。水灾沿用游戏水体模拟，新版通过临时源缓存适配。预警只发出危险事件，居民行程、庇护所与疏散车辆由原生机制处理；默认警报范围为受灾区域。

## 操作

游戏内独立“灾难”按钮，F9 开关面板。选择灾难即进入地图触发状态，左键点击有效位置提交一场灾难，成功后恢复之前的工具。右键、Esc 或关闭面板取消。参数沿用当前设置，触发前仍可调整；无效目标提示重选。火灾必须选对应建筑或野生树；天气可选地面。

洪水、海啸只显示强度与时长：点击想影响的位置，自动寻找附近水域并决定推进方向。新版洪水不要求原始水源实体；海啸仍需要海水。零预警陨石保留至少 3 模拟秒的坠落动画。

地震表现为三轮震动扬尘、视觉裂纹和碎片；陨石表现为加速坠落、尾焰、撞击闪光、碎片和烟尘消散。视觉只读模拟时钟，不操作玩家镜头、不承担伤害逻辑。每场最多 64 个烟尘、24 个尾焰及 24 个碎片，最多显示 8 场，冲击后 14 模拟秒内结束；停止、加载和销毁时清理。透明纹理、网格和材质共享，无新增粒子系统依赖。上述视觉和实际涨水仍待手动实机验收。

停止按钮只停止带有本 Mod 强度变体引用的事件，不影响原生随机灾害；停止不修复已造成的破坏。加载存档与切换工具会清除旧目标。

## 界面设计

- 调性：游戏内灾难工具，紧凑、可覆盖地图的浮动面板。
- 色彩：面板深蓝 #203747，标题栏 #29485c，文字 #eef5f8，次级文字 #adbfcb，选择蓝 #5bbde1，危险操作橙 #ed874f。
- 字体：使用游戏内 Noto Sans SC 中文字体，标题 19px，正文 15px，说明 13px。
- 布局：标题/关闭；地图触发提示与取消/再次触发；两列灾难选择；强度与计时等参数；独立避难；正在发生的本 Mod 灾害与停止。
- 重点：灾难类型图标与强度刻度。避免大屏仪表盘、装饰统计卡片和循环动画。

## 验收

1. 对本机 DLL 编译，Release 不包含开发 HTTP 服务。
2. 浏览器验证按钮、选点状态、范围、键盘、重复挂载与主菜单隐藏；这仅证明 UI 逻辑。
3. 游戏启动读取实际目录与灾难目录，验证事件创建与终止；测试存档不保存，禁用本次测试会话自动保存。
4. 游戏截图证明面板实际显示；未完成的实机项明确记录。

发布内容只包含自己的 DLL 与说明，不打包游戏 DLL。卸载后界面与工具消失；已有城市损伤不可逆，建议先停止本 Mod 灾害并另存备份。
