## 此次修复

- 海啸手动测试反馈无明显效果。旧版在远处地图边缘造波，忽略点击位置。本轮改为自动寻找点击点附近水域并决定推进方向；水灾面板只保留强度和时长，新版洪水不依赖原始水源实体。实际波高与漫岸尚待实机复测。
- 地震新增三轮扬尘、视觉裂纹和碎片；陨石新增加速坠落、尾焰、撞击闪光、碎片及烟尘。零预警陨石至少保留 3 模拟秒坠落，伤害与坑洞逻辑沿用既有系统。新图形尚未实机观察，不能用旧截图代表此次视觉效果。
- 本轮实际水灾与视觉计算代码的 49 个边界检查通过；此前只读水深网格输入能自动找到城区北侧海水。面板模拟回归确认洪水、海啸无方向/预警/范围控件并保留时长；`tests/ui-water-preview.png` 是浏览器模拟截图。
- 本轮最终 Release/Debug 构建均为零警告、零错误。2026-10-06 04:18 确认没有活动游戏进程后安装；上一实装版本备份到 `%LOCALAPPDATA%/DisasterControlPanel/backups/20261006-041857-654/`，已安装 DLL 与 manifest 校验一致，Release 类型列表无开发服务。
- 2026-10-06 简化触发：点击灾难类型直接准备地图触发，左键选有效位置即提交一次，成功后自动退出；右键、Esc 和关闭面板取消，保留当前参数。浏览器模拟交互回归通过，Release/Debug 构建均为 0 警告、0 错误；已在游戏退出时安装并备份上一候选版，实际地图射线与工具切换仍由用户手动复测。
- 开发接口曾在响应写入失败后再次设置 HTTP 状态码，造成“headers are sent”异常。现在先处理请求、再单次发送响应；网络断连和关闭失败记录为警告，不进入游戏更新错误处理。
- 上次将坑洞系统放在嵌套的模拟系统调度中，实机建筑冲击发生后坑洞仍未执行。改为直接注册到 `PostSimulation`，经执行计数和地形高度读回确认生效。执行计数仅在 Debug 中编译。
- 本机有已退出但仍可枚举的游戏进程对象。安装/卸载脚本现在用 `HasExited` 区分它们与仍在运行的游戏，保持实际运行时的保护。
- 本次启动 Steam 前清除了继承环境中的 `ELECTRON_RUN_AS_NODE`，恢复 Paradox 启动器正常运行。这是验收环境处理，不改变玩家的启动配置。

## 地形限制

本地图空地原高度仅约 13.5 米，地形的最低高度限制使坑深无法达到参数中的 23/30 米。原生道路和建筑地基会覆盖部分坑形，建筑区域地形读回不能代表未覆盖空地的坑深。本版不额外切断道路或管线。
