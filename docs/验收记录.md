## 验收中修正

- Cohtml 不完整支持浏览器表单控件：滑块/下拉框改为分档按钮；普通字体改为游戏中文字体。
- 事件从 UI 阶段直接创建会跳过正确的原生初始化时机：改为捕获请求，在 Modification1 创建，随后由原生 Modification2/IgniteSystem 初始化。
- 点燃后树木会更换 ECS 查询分组：验收脚本改为按实体 ID 查询，不再用前 12 个搜索结果推断是否着火。

## 验证范围

没有验收大型人口城市长时间负载、所有消防调度行为、破坏程度与等级的逐档统计、含活动 Mod 灾害的存档重载、其他游戏版本或所有第三方 Mod 组合。

地震、海啸、陨石和塌陷未实现。原版随机灾害不受停止按钮控制。停止本 Mod 灾害不会恢复城市损伤。

## 后续核对更正

离线资源核对进一步确认：海啸、洪水、雷击、建筑倒塌和车辆失控事故均有原生 EventPrefab，并列在启用的 EventsCollection 中。海啸使用 Sea / Sine 水位变化；洪水使用 River / RainControlled，SoilWaterSystem 有按降雨累积启动、更新与停止的流程。0.1.0 尚未接入这些事件，资源与代码证据不能代替完整行为的实机验收。详见[原生灾难核对](原生灾难核对.md)与[提取记录](native-event-inventory.json)。
