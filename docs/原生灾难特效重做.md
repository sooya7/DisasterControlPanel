# 原生灾难特效重做（2026-10-06）

本轮替换地震、陨石的烟尘和火焰渲染方式，重新编排发生过程。用户提供的截图显示烟尘成为硬边方片拼接的圆环，这个版本不能作为合格效果。

## 根因和改动

离线读取本机游戏 `globalgamemanagers.assets`：`HDRP/Unlit` 的 ForwardOnly 通道有 8 个片元程序，全部不含 `_SURFACE_TYPE_TRANSPARENT`。旧版代码设置透明混合参数和关键词，无法找回游戏构建时剔除的透明版本。此前只对照公开 HDRP 源码检查混合参数，没有检查实际打包版本，这是验证缺口。

删除自制透明方片、程序噪声烟尘图集、双点火焰线，改用游戏已有的 `DustcloudSmall`、`Dustcloud`、`ExplosionTimed`、`FireMovingMedium`。本机原生粒子着色器存在；游戏尘云使用多帧贴图，粒子透明、光照、湍流与淡出交给原生 VFX。

适配遵循本机 `Game.Effects.VFXSystem` 的数据契约：私有 64×3 RGBAFloat 纹理，依次写入世界位置和强度、弧度旋转、三轴尺度；同时传入 Count、风纹理和地图偏移。通过 PrefabSystem 读取资源引用，不修改原生共享特效、不把游戏贴图或程序集装进发布包。

- 陨石：移动尾焰、短促撞击爆炸与光照、24 个不同速度且减速的贴地尘源、8 个延迟的中心烟柱源。中心不再被所有烟尘同时向外移动而掏空。碎块落地短暂扬尘，随后停止发射。
- 地震：24 条不等长、非等角的分支裂隙，扬尘锚定裂隙，按距离延迟，三轮脉冲有各自时序。已有尘云继续消散，不因下一轮到来而瞬间回到起点。
- 水面白沫共用的错误透明方片也被移除，换成原生 `BoatFoam01`，发射仍受真实水深和水面坡度约束，32 个采样点。它只作水面装饰，不改变水位、波浪传播或地形。

## 边界与验证

保留伤害、触发界面、避难、存档和水模拟。最多同时 8 场视觉，每个 VFX 最多 64 个发射源；图本身粒子容量由游戏定义。陨石撞击后视觉时钟最多 2 倍速；暂停同步暂停原生图，停止、换城及系统销毁释放本 Mod 的对象和纹理。资源缺失会记录警告，不回退到坏贴片。

离线验证包括 Release/Debug 编译、1–10 级发射编排测试、环状分布反例、延迟与发射截止、原生资产参数及已编译着色器核对，以及已有水灾契约回归。

**未启动或操作游戏。离线编排预览只显示发射位置和时间，不模拟原生 GPU 粒子的最终光照、遮挡、风场、透明排序和密度，不是游戏截图或视觉验收。** 原生资源运行时是否按预期加载、多个灾害的性能和最终观感，仍需之后实机确认。

证据与可恢复基线：`work/live-evidence/codex-takeover/smoke-fix/`，位于本项目上级工作目录。知识库工具当前不可用，验证结论先保存在本记录与证据中。
