# 地震、陨石动画重做与一代风格水灾（0.2.2，2026-10-09）

用户要求：重做陨石、地震动画；看洪水、海啸能否做到一代（Cities: Skylines 1）那种效果。

结论先说：**能做到一代的主要观感**——海啸是一道从远海推来、越近岸越高、冲上岸后继续往内陆卷的浪墙，洪水是水边一步步漫进相连的低洼街区。做法仍是往原生水体的源缓存里加临时水源，水流、漫岸和退水由游戏自己的水体模拟完成。和一代的差别见文末“边界”。

本轮只改源码，**没有启动游戏，也没有本机游戏 DLL 可编译**（见“验证”）。

## 地震：一条断层，而不是放射状裂纹

旧版是从震中向四周放射的 24 条细线，像蜘蛛网，且 LineRenderer 只是贴地的平涂线条。真实地震和一代都是一条断层线横穿地面。

- **断层几何**：过震中、方向随落点固定的一条断层，向两侧各延伸约 0.45–0.67 倍震动半径（10 级约 1.1 公里/侧）。每侧由多段 140–370 米的雁列断段组成：每段略微转向、侧向错开几米并与上一段重叠，迹线带低频弯曲和小锯齿。部分断段末端向前分出约 15–150 米的分支裂缝。
- **裂口网格**：每个迹线点 7 个截面顶点——两侧翻起的土埂、内缘、黑色深缝。土埂用受光照的土层材质（程序生成的土块纹理），深缝近黑色。主断层一侧的土埂随震动升高成断坎（10 级约 1.25 米）。网格按地形逐点贴合（采样中心高度和横向坡度），离地 0.32 米。
- **生长**：破裂尖端从震中向两侧跑开，第一轮到 55%、第二轮 82%、第三轮全长；尖端后方很短的距离内逐渐张开，所以尖端是尖的。每一轮震动把裂口猛地推宽一次（带轻微回弹）。
- **扬尘**：破裂尖端奔跑时冒尘；刚撕开的一段喷尘；第二、三轮震动时整条断层抖出尘。建筑扬尘、镜头震动、声音保留。去掉了旧版向外扩散的尘环（看起来像人工圆环）。
- **寿命**：裂缝在事件结束后保留到冲击后 75 秒，最后 4 秒沉入地面消失。仍是视觉效果，不改地形和道路。

## 陨石：长烟迹斜落、火球、冲击环、蘑菇烟柱、熔融坑

- **入场**：从约 5.2 公里外、48° 仰角斜落，可见下落固定约 7 个真实秒（加速游戏时按模拟速度拉长，不超过预警时间）。旧版在长预警时会在空中慢慢挪几十秒。
- **头部**：碎裂岩石 + 发光等离子尾（4 段锥体，白热 → 黄 → 橙 → 暗红，长度随飞行距离增长，最长约 9 倍岩体）、原生火球、尾焰和火星。光源随火球移动。新增由远及近、越来越响的呼啸声，撞击时切到爆炸声。
- **烟迹**：沿整条轨迹 64 个点（越靠近地面越密）在火球经过时冒烟，持续约 18 秒，随风飘散；另有 32 个灰尘点加厚烟迹。
- **撞击**：
  - 火球穹顶：0.14 秒内鼓到约 1.7 倍坑半径，白热转橙红，0.9 秒内压扁、沉入烟尘。
  - 冲击尘环：48 个尘源组成的参差尘环，3 秒内减速扩散到约 3.5–5.7 倍坑半径。
  - 蘑菇状烟柱：16 个尘源组成的烟柱上升到约 90–290 米，8 个尘源在顶部铺开成帽，约 20 秒后散去。
  - 原有贴地扇形尘、爆炸、火星、36 块炽热碎岩（冷却变暗、落地扬尘）保留。
  - 熔融坑：坑底一块贴合地形的熔岩面和焦黑坑缘，坑刷落下后几秒内重采样几次高度；约 6.5 秒时间常数冷却成焦黑，之后沉入地面。坑内火焰延长到 18 秒，烟延长到 30 秒，视觉整体保留 40 秒。

渲染约束不变：本机游戏打包的 HDRP 没有透明着色器变体（见[原生灾难特效重做](原生灾难特效重做.md)），所以软的烟、尘、火都用游戏原生 VFX 图；自制网格都是不透明的，发光部分用与曝光无关的自发光（白天也亮），实体部分用受光照材质。

## 海啸：一代式浪墙 + 冲上岸

旧版浪墙只在海面上推进，到岸边就停在最后一格海面上“顶着”，靠水体自己漫上岸；浪峰每次跳 112 米。

- **浪高随水深变化**：远海约 60% 高度，越近岸越高，到岸边达到全高（类似浅水增高）。
- **冲上岸（run-up）**：每一列从最后一格海面开始沿推进方向往内陆延伸，每 7 米采样地形，只要地形低于“随内陆距离衰减的浪面”就继续，碰到更高的地面就停。内陆最远 0.25 公里（1 级）到 3 公里（10 级）。内陆源的整个圆盘都低于浪面，不会把水直接灌到山脊后面。高地、海堤高于浪面就挡得住；10 级可以越过较低的堤。
- **浪峰平滑移动**：相邻两格之间插值，圆盘半径按两格安全圆盘的并集收缩（离线测试逐点验证不越出），不再一跳 112 米。
- **时序**（按 150 秒造波时间）：0–30% 岸边退潮；4% 远海起浪，到 50% 推进到内陆最远处（越到后面越慢），保持到 58%，72% 前消散；60–97% 半高尾浪。浪峰过后由原生水体自然回流、退水。
- **表现**：浪峰白沫、浪后翻滚的白水、浪顶水雾，岸上同样显示；新增跟随浪峰的低沉轰鸣（循环，音量随浪高）。
- 避难预警沿用原有判断。

## 洪水：水漫进相连的低洼街区

旧版只在已有水面上加源，水能否上岸全靠水体自己溢出。

- **漫延范围**：从点击的水面做“最小翻越高度”搜索（64 米网格，每段按原生 7 米尺度采样）：每块陆地记下水要涨到多高才能从水面流到这里，以及它由哪段水面供水。比满级涨幅还高的山脊挡住其后所有地方；堤坝被越过之前，堤后的低地不进水。陆地范围在原水域范围外再延伸 0.25–2 公里（按等级）。
- **逐步漫进**：水位按原有曲线上涨（时长前 65%），某块地在水位高出它 0.4 米时才开始加源，目标就是当前水位，所以水边是一圈一圈往外爬的，不是瞬间铺满。每块地的源圆盘整体低于它的淹没高度，不会填进水到不了的洼地。每 128 米一个源，最多 320 个，最低的地先淹。
- **表现**：刚被淹到的水边显示白沫和翻滚的浑水。
- 避难预警额外包括这些会被淹的陆地附近的建筑。
- 到时或停止后不再加源，水由原生模拟自然退去或滞留在洼地。

## 验证

- `tests/vfx-contract`、`tests/water-contract` 离线运行通过（实际生产代码）。新增检查包括：陨石入场时长、只前进、烟迹点与火球实际位置一致、火球/冲击环/烟柱/熔融坑有界且会结束；断层是一条线而非放射状、两侧延伸、从震中开始、只增长、每轮加宽、尖端先闭合、扬尘只在撕裂和余震时、网格不超过 16 位索引；浪墙冲上低平海岸、被高于浪面的海堤挡住、强浪越过低堤、悬崖海岸不上岸、内陆单元低于衰减浪面、浪越近岸越高；浪峰插值圆盘始终在两格安全圆盘内；洪水沿河谷两岸漫开、最低处先淹、1 级只淹最低的岸、堤坝在被越过前保护堤后、越过后才淹。
- 游戏侧代码（`DisasterVisualSystem`、`WaterDisasterSystem` 等）用 Unity 2021.3 的 UnityEngine 引用程序集、Unity.Mathematics 源码和按现有用法写的游戏 API 桩做了**类型检查，编译通过**，故意引入的错误能被查出。这不等于在 1.6.2f1 的真实程序集上编译，请用 `Build.ps1` 编译确认。
- **没有进游戏**：浪墙实际高度和推进速度、上岸距离、洪水漫进速度、断层贴地效果（道路桥面略高于地形时裂缝可能被路面盖住）、等离子尾和火球在白天/夜晚的亮度、原生 VFX 在这些尺度下的观感和帧耗，都要实机看。

## 性能提示

- 触发时一次性规划：10 级洪水约 1–2 百万次地形/水深采样，10 级海啸约 1 百万次，预计有一次短暂卡顿（约零点几秒）。
- 每帧水源：洪水 ≤ 256 水面源 + ≤ 320 陆地源；海啸每列 ≤ 2 浪 × 3 源 + 退潮源（10 级约 57 列）。
- 每场陨石视觉 ≤ 12 个原生 VFX 实例（每个 ≤ 64 发射点）+ 若干小网格；地震断层网格约 4–5 千顶点，前 9 秒逐帧重建，之后静止。最多同时 8 场。

## 可调参数

- 断层长度/宽度/断坎：`DisasterVfxRules.FaultHalfLength / FissureWidth / ScarpHeight`。
- 陨石入场距离、仰角、可见时长：`MeteorEntryDistance / MeteorElevation / MeteorFlightTime`。
- 海啸上岸距离和衰减：`WaterDisasterRules.RunUp / LandDecay`；近岸增高 `Shoal`；时序 `WaveWall`。
- 洪水陆地范围和源数量：`LandReach / PlainLimit / PlainStep`。

## 与一代的差别

- 一代水体带速度场，浪本身有动量；本作的源只设定目标水位，浪的“冲劲”靠移动的源来模拟，冲上岸的距离由上面的衰减规则决定，不是物理算出来的。
- 一代地震会真的在地形上切出裂缝并切断道路；这里仍是视觉裂缝，不改地形、道路和管线。
- 原生水面渲染决定浪墙的最终样子；白沫、水雾只是点缀。
